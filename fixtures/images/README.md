# Image fixtures

Synthetic images used by `crates/media` tests and benchmarks. All are generated by
`crates/media/examples/gen_fixtures.rs` (no third-party artwork; same licence as the repo):

```bash
cargo run -p gpui-chat-media --example gen_fixtures   # needs img2webp (brew install webp)
```

| File | What | Encoder |
|---|---|---|
| `static.png`, `static.webp` | 28×28 still, pixel (0,0) = RGBA(200,100,50,128) | `image` (WebP lossless) |
| `animated.gif` | 28×28, 4 frames, delays 100/50/**0**/30 ms, right half transparent | `image` |
| `animated.webp` | same frames, delays 100/50/**10**/30 ms, sub-rectangle frames | `img2webp -lossless -min_size` |
| `animated-112.gif`, `animated-112.webp` | 112×112 (4x emote), 24 frames at 40 ms | `image`, `img2webp -lossless` |
| `corrupt.png` | first half of `static.png` | — |
| `oversized.png` | 4096×16, over the default 2048 px decode limit | `image` |

The bold delays must be clamped to 100 ms by the decoder. Tests assert on these exact values.
