- **Protect a broken settings file from being overwritten** (found in PR 0.3) — loading never touches it, but a later `save` (settings UI) would clobber it; back it up to `settings.toml.bak` or require confirmation when the last load had an error.

- **Sidebar rows have no room for the title** (found in PR 3.5) — `SidebarMenuItem` rows are one fixed-height line, so the title is only in the tooltip of the dot/viewers part; a custom row element (or two-line rows) could show it.

- **Poll failures are only logged** (found in PR 3.5) — `StreamSnapshot::error` is not shown anywhere; a faint "stream info unavailable" hint in the header would say why a live dot is stale.

- **Thread popover closes only with its button** (found in PR 3.4) — no Esc, no click-outside, and it covers the top right of the chat while open; a keyboard shortcut for Reply on the newest/selected message does not exist either (Reply is the hover button, the right-click menu, or nothing).

- **Reply context line is not selectable or live** (found in PR 3.4) — it shows the parent's text as of the reply (`reply-parent-msg-body`), with no strike-through when the parent is later deleted, and it is not part of copy/selection (PR 5.6).

- **Recents are by recency, not frequency** (found in PR 3.3) — `Recents` keeps the 40 emotes used last, shared by every pane; a per-channel or frecency list would fit people who use a few emotes in one channel and others elsewhere.
- **Twitch tab is one flat list** (found in PR 3.3) — Twitch's `Get User Emotes` says which channel (`owner_id`) and tier (`emote_type`) each emote belongs to; group the tab under channel headings (the channel's own first), with the channel names from `Get Users`.

- **Completion list sits at the box's left edge** (found in PR 3.3) — it is not under the word being completed; anchor it to the caret (`InputState::range_to_bounds` gives the rect).
- **Subsequence matches add noise to longer queries** (found in PR 3.3) — `:monka` ends with `MasonLookingAtYou`; they sort last, but could be left out once the query has 4+ characters and anything better matched.
- **No emote completion while logged out** (found in PR 3.3) — the box is disabled without a login, so the third-party emotes that load anonymously cannot be browsed; a read-only picker would let a logged-out user look at them.
- **Picker shortcut is not in the menus** (found in PR 3.3) — ⌘E / Ctrl-E (`EMOTE_PICKER_LABEL`) is only on the button's accessibility label; a *Channel → Emote Picker* item would make it discoverable (GPUI menu actions are global, so it needs the focused composer to answer it).
- **Per-keystroke cost of ranking a large catalog** (found in PR 3.3 review) — `rank` lowercases every candidate name on each keystroke and `Recents::rank_of` is a linear scan; with a 10 000-emote catalog precompute lowercase names in `EmoteCatalog`, keep recents in a map, and pass the chatter index as recency instead of `position`.
